# Guía de uso — Funeraria (para empleados)

Esta carpeta explica **paso a paso** cómo usar la web. Está pensada para personas **sin conocimientos de informática**: solo hay que seguir los números.

**Versión en catalán:** [ca/README.md](./ca/README.md)

## Antes de empezar

- Necesitas **Internet** y un **navegador** (Chrome, Edge o Safari).
- La dirección de la web la facilita la funeraria (por ejemplo `www.pujols.cat` o una dirección temporal mientras se prueba).
- **Panel de administración:** añade `/admin` al final de la dirección (ejemplo: `https://www.pujols.cat/admin`).
- Si algo no funciona: cierra el navegador, vuelve a abrirlo e inténtalo otra vez. Si sigue igual, anota qué pantalla veías y llama a soporte.

## Orden recomendado la primera vez

1. [Configuración](./configuracion.md) — datos de contacto y logo.
2. [Lugares](./lugares.md) — al menos una iglesia, un cementerio y una sala de vetlla.
3. [Poemas](./poemas.md) — opcional, pero útil antes de dar códigos a familiares.
4. [Esquelas](./esquelas.md) — el flujo principal del día a día.
5. [Flores](./flores.md) y [Contenido home](./contenido-home.md) — cuando toque.

## Palabras que verás a menudo

| Palabra en pantalla | Significa |
|---------------------|-----------|
| **Activa** | El familiar puede entrar con su código. |
| **Visible** | La esquela aparece en la lista pública de la web. |
| **Esquela completa** | Marca interna de que ya está lista (lista). |
| **Código de acceso familiar** | Clave que das al familiar (ejemplo: `DEMO1234`). |
| **Pendent retocar** | El familiar envió una foto; hay que retocarla y subirla. |
| **Guardar / Desar** | Guardar los cambios. |
