# Guia d'ús — Funerària (per a empleats)

Aquesta carpeta explica **pas a pas** com utilitzar la web. Està pensada per a persones **sense coneixements d'informàtica**: només cal seguir els números.

**Versió en castellà:** [../README.md](../README.md)

## Abans de començar

- Cal **Internet** i un **navegador** (Chrome, Edge o Safari).
- L'adreça de la web la facilita la funerària (per exemple `www.pujols.cat` o una adreça temporal mentre es prova).
- **Panell d'administració:** afegeix `/admin` al final de l'adreça (exemple: `https://www.pujols.cat/admin`).
- Si alguna cosa no funciona: tanca el navegador, torna'l a obrir i prova-ho un altre cop. Si segueix igual, anota quina pantalla veies i truca a suport.

## Paraules que veuràs sovint

| Paraula a pantalla | Vol dir |
|--------------------|---------|
| **Activa** | El familiar pot entrar amb el seu codi. |
| **Visible** | L'esquela apareix al llistat públic de la web. |
| **Esquela completa** | Marca interna que ja està llesta (llista). |
| **Codi d'accés familiar** | Clau que dones al familiar (exemple: `DEMO1234`). |
| **Pendent retocar** | El familiar ha enviat una foto; cal retocar-la i pujar-la. |
| **Desar** | Guardar els canvis. |
